
# TorrentLeecher - Cloud Downloads

## Project Overview
TorrentLeecher is a web application that allows users to download torrents directly to Google Drive without exposing their IP address or installing any software. The application provides a secure and private way to download torrents by leveraging cloud infrastructure.

## Key Features
- **Direct to Cloud**: Download torrents directly to Google Drive without using local storage
- **Privacy Protection**: Keep your downloads private and secure without exposing your IP address
- **No Installation Required**: Web-based solution with no software installation needed
- **File Management**: Organize downloaded files with folder creation and file management options
- **Download Tracking**: Monitor download progress with real-time updates
- **Responsive Design**: Works seamlessly across desktop and mobile devices

## User Experience
The application provides an intuitive interface for users to:
1. Paste magnet links to start downloads
2. Track the progress of ongoing downloads
3. Manage and organize completed downloads
4. Create folders for organizing files
5. Access downloaded content directly through Google Drive links

## Current Setup
The project is currently set up with a minimal viable product that demonstrates the core functionality. The frontend is built with React and communicates with a Supabase backend for data persistence and real-time updates.

The application uses a staging environment for development and testing, with plans for a production deployment in the future.

## Target Audience
- Privacy-conscious internet users
- Individuals with limited local storage
- Users seeking convenient cloud-based torrent solutions
- People who want to access downloaded content across multiple devices
